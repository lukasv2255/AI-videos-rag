# 80. Open source AI vs. proprietární modely — etický rozměr

Zdroj tématu: 08_etika_spolecnost.md

---

1/5 Modelů přibývá. Otázka není jestli je použiješ, ale jak si uchráníš kontrolu. Proprietární či open source — obojí má cenu.

2/5 Open source modely jsou dostupné všem, včetně těch se špatným záměrem. Ale detekce AI obsahu existuje. Problém: bude stejně nedostupná jako Photoshop fake dnes.

3/5 Prakticky: Silnější model lépe odolá prompt injection útokům. Jsou-li tvé agenty na internetu, sázej na top tier modely, ne na slabší varianty. Kontrola nad daty je levnější než oprava.

4/5 Etika není v modelu. Ty rozhodneš, jak ho použiješ. Když model generuje text jako tvůj zástupce, bude tě poznávat lépe než sám sebe. Tvoje notes jsou jeho mozek.

5/5 Checklist: Ulož API klíče mimo workspace / Přidej safety layer do promptu / Valcuj silný model / Zálohuj paměťové soubory / Ptej se sám sebe: chci kontrolu, nebo automatizaci?
