# 26. n8n vs. Zapier vs. vlastní agent — srovnání

Zdroj tématu: 03_agenti_automatizace.md

---

1/5 Zapier a Make jsou lineární. Agent je vědomý. Když jste v Zapier, každý krok je ostrov. V agentu? Vidí celý kontext všeho, co dělal. Rozdíl mezi automatizací a inteligencí.

2/5 Prakticky: s agentem extrahujete data z e-mailu jednoduše ("prosím najdi počet cestujících"). V Zapier byste psali HTML parser, který se rozbije při změně formátu. Agent se přizpůsobí.

3/5 Ale pozor. Ne každá úloha potřebuje agenta. Když chcete poslat příspěvek na X, LinkedIn a blog? Sekvence je lepší. Agent by mohl hallucinātor a poslat twice. Kontrola > flexibilita.

4/5 Agenti mají tři znaky: interakce s prostředím, nástroje k dosažení cíle, nedeterminismus. Chatbot na n8n bez nástrojů? Workflow bez interakce? Nejsou agenti, jsou užitečné workflow.

5/5 Než si zvolíte: je úloha sekvence (Zapier stačí)? Nebo potřebuje rozhodování (agent)? Otestujte oba přístupy. Správný nástroj je ten, který skutečně řeší problém bez zbytečné složitosti.
